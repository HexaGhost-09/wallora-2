## ✨ Features that WOW

*   **🔍 Smart Search**: Find the perfect wallpaper in seconds with our optimized real-time search engine.
*   **📐 Responsive Precision**: Beautifully optimized for mobile, tablet, and desktop (Windows). No more stretched pixels!
*   **📂 Styles & Categories**: Browse through carefully curated categories from Minimalist to Abstract.
*   **💖 Live Interaction**: Like, save, and sync your favorites across devices in real-time.
*   **⚡ Blazing Fast**: Powered by Flutter for native performance and butter-smooth animations.
*   **🔔 Instant Updates**: Never miss a feature with built-in update notifications for all platforms.

## 🚀 Getting Started

### 1️⃣ Prerequisites
Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed on your machine.

### 2️⃣ Installation
```bash
# Clone the universe
git clone https://github.com/HexaGhost-09/wallora-2.git

# Enter the dimension
cd wallora-2

# Get the magic beans
flutter pub get
```

### 3️⃣ Run Project
```bash
# Launch the experience
flutter run
```
