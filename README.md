## ✨ Discover Wallora

- **Smart search** — Find wallpapers quickly.
- **Automatic tag collections** — Wallpapers are grouped by their tags automatically.
- **Curated categories** — Browse wallpapers by style and category.
- **Favorites** — Like and save wallpapers for later.
- **Responsive interface** — A clean experience across supported screen sizes.
- **Update notifications** — Get notified when new releases are available.

## 📱 Supported platforms & devices

Wallora's release workflow builds packages for these platforms:

| Platform | Supported devices | Release format |
| --- | --- | --- |
| **Android** | Android phones and tablets | APK |
| **iOS** | iPhone and iPad | IPA |
| **Windows** | Windows desktop PCs and laptops | Installer / portable bundle |
| **Linux** | Linux desktop PCs and laptops | TAR.GZ bundle |
| **macOS** | Mac computers | DMG / ZIP |

> Device compatibility can vary by OS version and hardware. Check the release notes for platform-specific requirements.
